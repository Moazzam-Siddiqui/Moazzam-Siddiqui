# Build this animated profile README for your own GitHub

Everything on this profile is plain SVG generated by Python. Animations are CSS/SMIL inside each SVG (GitHub blocks JavaScript), and a daily GitHub Action keeps the stats fresh. No external image services or tokens to set up (the snake uses the open-source [Platane/snk](https://github.com/Platane/snk) Action).

| File | What it is | Refreshed |
|---|---|---|
| `header.svg` | Name with animated gradient + typing/deleting role loop | daily |
| `info-card.svg` | neofetch-style card with live stats + language bar | daily |
| `globe.svg` | Rotating 3D dotted Earth, home pin + packet arcs to cloud regions | daily |
| `tech-sphere.svg` | Your stack as labels on a rotating 3D sphere | daily |
| `contrib-skyline.svg` | Isometric 3D city of your contribution year | daily |
| `contrib-heatmap.svg` | Animated contribution grid + streak stats | daily |
| `contrib-snake.svg` | Snake eating your contribution graph ([Platane/snk](https://github.com/Platane/snk)) | daily, CI only |
| `ascii-portrait.svg` | Your photo as animated ASCII art | when you re-run it locally |

Total time: about 15 minutes.

---

## 1. Prerequisites

- Python 3.11+ and git
- A GitHub account (examples below use `YOUR_USERNAME`)

## 2. Create your profile repo

GitHub shows the README of a repo named **exactly like your username** on your profile.

1. Go to <https://github.com/new>.
2. Repository name: `YOUR_USERNAME`, visibility **Public**, no starter files.

## 3. Copy this project

```bash
git clone https://github.com/DIV297/DIV297.git YOUR_USERNAME
cd YOUR_USERNAME
rm -rf .git data/*.json *.svg source-photo.png source-prepped.png
git init -b main
```

## 4. Put in your details

Edit **`scripts/config.py`**. It's the only file with personal content:

```python
USERNAME = "YOUR_USERNAME"        # must match your GitHub login
NAME = "Your Name"
PROMPT_USER = "you"               # shown as you@github
ROLES = ["Backend Engineer", "..."]  # cycled by the typing animation
TAGLINE = "City · what you build"
INFO_ROWS = [("Role", "..."), ...]   # neofetch rows; {placeholders} fill from live data
```

Also in `config.py`:

- `HOME` and `REGIONS`: the globe's pin and the cloud regions the arcs fly to, as `(name, lat, lon)`.
- `TECH`: the labels on the tech sphere, grouped by category (each category gets its own colour).

Available placeholders in `INFO_ROWS`: `{uptime}`, `{top_langs}`, `{public_repos}`, `{stars}`, `{total}`, `{current_streak}`, `{longest_streak}`.

In `README.md`, replace `divansh@github` in the three `<h3>` lines and the `alt` text with your own.

## 5. Install and render

```bash
python3 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r scripts/requirements.txt

cd scripts
python fetch_contributions.py        # -> data/contributions.json
python fetch_profile.py              # -> data/profile.json
python render_all.py                 # -> header, info-card, skyline, heatmap SVGs
cd ..
```

Open any `.svg` in Chrome to watch the animation. `contrib-snake.svg` is only created by the GitHub Action, so it shows as a broken image locally until the first workflow run.

## 6. ASCII portrait (optional, local only)

```bash
pip install -r scripts/requirements-portrait.txt
python scripts/prep_photo.py                 # uses your GitHub avatar
# or: python scripts/prep_photo.py my-photo.jpg
python scripts/make_ascii_svg.py
```

- The first run downloads a 5 MB background-removal model (`u2netp`). For cleaner edges on a fast connection, use the 170 MB model: `REMBG_MODEL=u2net_human_seg python scripts/prep_photo.py`.
- Best input: a front-facing photo with your head and shoulders and good light on your face.
- To frame it differently, adjust `CROP` at the top of `make_ascii_svg.py`. `COLS` sets the level of detail.

## 7. Push and turn on the daily refresh

```bash
git add .
git commit -m "feat: animated profile README"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_USERNAME.git
git push -u origin main
```

Then on GitHub:

1. **Settings → Actions → General → Workflow permissions** → select **Read and write permissions** → Save.
2. **Actions → Update profile art → Run workflow**. In about a minute it commits fresh `data/*.json` and SVGs.

From now on it runs every day at 06:17 UTC, and on every push to `main` that changes something other than `data/` or the SVGs.

## 8. Recommended: count private work

If most of your commits go to private or org repos, open your profile page and select **Contribution settings → Private contributions**. Otherwise the scraper only sees public activity.

## Customising

| Want to change | Where |
|---|---|
| Colours / theme | `scripts/common.py` (`GREEN`, `CYAN`, `PALETTE`, ...) |
| Globe tilt, size, spin speed | `scripts/render_globe_svg.py` (`TILT`, `R`, `PERIOD`) |
| Globe land dots | `scripts/land_points.json`; rebuild with `build_land_points.py` from [Natural Earth](https://github.com/nvkelso/natural-earth-vector) |
| Building colours, height, angle | `scripts/render_skyline_svg.py` (`TOPS/LEFT/RIGHT`, `HMAX`, `IX/IY/JX/JY`) |
| Typing speed of roles | `scripts/render_header_svg.py` (`slot`, `0.055` s per char) |
| Language bar colours | `LANG_COLORS` in `scripts/render_info_card.py` |
| Card order / sizes | `README.md` (keep each row at 860: 370 + 490, or 430 + 430) |

## How it works

```
GitHub Action (daily)
  fetch_contributions.py  scrapes github.com/users/<you>/contributions (public HTML, no token)
  fetch_profile.py        REST API: repos, stars, language bytes (uses the built-in GITHUB_TOKEN)
  render_all.py           data/*.json -> SVGs with embedded CSS/SMIL animation
  Platane/snk             contrib-snake.svg
  git-auto-commit         commits only data/ and *.svg, tagged [skip ci]
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `No contribution cells found` | GitHub changed the calendar markup. Update the selectors in `fetch_contributions.py`. |
| Workflow fails at the commit step | Turn on **Read and write permissions** (step 7.1). |
| Profile shows old images | GitHub caches images for a few minutes. Hard-refresh, or wait. |
| Animation doesn't replay | Every animation plays on page load. Reload the profile. |
| `prep_photo.py` hangs | It's downloading the model. Check your connection, or pre-download `u2netp.onnx` into `~/.u2net/`. |
| Portrait looks flat | Use a brighter photo, or lower the `** 0.8` gamma in `make_ascii_svg.py` for more contrast. |
